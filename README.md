源码地址：ym7k.com/17939/

涉案精查小程序系统，面向法务人员、企业风控、合规专员以及相关办案辅助人员打造，是一套轻量化的司法信息查询工具方案。依托小程序载体，无需安装 APP，搭配配套管理后台，聚焦案件信息检索、涉案主体核查、司法资料归集、风险筛查等业务需求，帮助使用者高效完成涉案信息精查工作，为尽调、风控、案件辅助核查提供数据支撑。
<img width="870" height="929" alt="5c065ecdb2947aa01ad3a04667b5e7e9" src="https://github.com/user-attachments/assets/352787d0-ae4a-4695-8f08-a81533a7e267" />

主体信息查询是系统基础核心能力。使用者可以输入企业名称、自然人姓名、证件标识等关键信息，定向检索对应的司法相关记录。系统会归集该主体关联的涉诉案件、被执行人信息、失信记录、限制高消费、开庭公告、裁判文书、送达公告等多维度司法信息，统一整理展示在查询结果页面。查询结果分类清晰，区分民事、刑事、执行等案件类型，每条记录标注案号、审理法院、立案时间、案件状态，方便使用者快速判断目标主体是否存在司法风险。

案件详情与资料查阅功能，支撑深度精查。点开单条案件记录，可查看完整案件概要、当事人信息、审理流程节点，支持调取对应的文书摘要内容。系统会梳理案件时间线，从立案、开庭、判决到后续执行环节依次呈现，直观还原整个案件发展过程。针对批量核查场景，支持批量导入名单进行筛查，一次性对多个主体开展风险检索，自动生成汇总清单，相比人工逐个查询，大幅提升尽调效率，适合企业合作前置风控、供应商背景筛查等场景。

风险标记与档案归档功能，方便使用者沉淀核查成果。在查询到风险信息之后，操作人员可以手动标注风险等级，添加备注信息，记录核查要点、风险说明。每一次查询任务都会生成独立的核查档案，保存查询主体、查询时间、检索结果、操作人信息，形成可追溯的核查台账。历史查询记录统一保存，支持随时调阅复查，不用重复发起检索，满足留痕归档的工作要求。

后台管理模块承担系统配置、权限管控与日志审计职责。管理员可以划分多级角色权限，严格管控查询权限，区分普通核查员、审核员、超级管理员。不同账号开放不同查询范围，敏感信息设置访问门槛，避免无关人员随意调取司法资料。系统完整记录每一次查询操作日志，记录查询账号、查询对象、查询时间，全程留痕，满足合规审计要求。后台还支持关键词管理、数据更新配置，维护检索数据源规则，保障信息稳定更新。

检索筛选与导出报表功能适配办公场景。查询结果支持多条件组合筛选，可以按照案件时间、法院、案件类型、风险类别进行过滤，快速定位重点风险条目。核查完成后，支持将本次精查结果导出报表，报表汇总主体基础信息、风险条目、案件清单，可直接用于风控报告、尽调材料整理，减少人工复制整理的工作量。小程序端适配手机端操作，外勤人员在外也可以随时发起查询，随时随地核验主体风险。

这套小程序系统以涉案信息精查为核心，把分散的司法信息整合到统一查询入口，实现主体检索、案件查阅、风险标注、档案留存、报表导出一体化。轻量化的小程序形态降低使用门槛，配套权限与日志机制守住合规底线，适合律所、企业风控部门、商业尽调机构用于前期风险排查，辅助工作人员快速识别合作方、相关主体的司法涉诉风险。
